既然散步有记录，陪猫的这几分钟也值得留下来。于是就有了 LuCat，把每只猫的陪伴时光从手腕记录到 iPhone。

## 用法很简单

在 Apple Watch 上选一只猫，点「开始」，然后安心撸猫。点击结束后自动保存，并同步到配对的 iPhone。回头翻日历，就能看到哪天陪了哪只猫、陪了多久，以及记录下来的互动动作。

## 每只猫都有自己的档案

添加猫咪、拍摄头像，还能点开头像放大看。家里有好几只猫，也能分开看数据。猪咪、小黑、小黄、小橘，都有各自的陪伴记录。

## 随手记录体重

正在长大的小猫、开始控制体重的胖猫，每次称完都能随手记一笔，回看每只猫咪的体重曲线变化。

## 提醒与小目标

忙归忙，也记得陪陪小猫咪。可以设置每天三分钟或三次互动的小目标。提醒通知还会轮流使用猫咪的头像。

## 回看互动变化

通过手腕运动数据查看动作时间轴和估算的互动力度。这里展示运动估计值，不能直接测量施加在猫咪身上的力或压力。
